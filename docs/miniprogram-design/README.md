## Tab Bar（3 个一级入口）

- 搜索 / 热搜 / 设置，icon 24×24 在上、label 10px 在下竖排
- 选中态：图标 + 文字变微信绿 `#07C160`；未选中：`#999999`
- 白底 + 顶部 1px 分割线 `#E5E5E5`，安全区底部预留

## 设计系统（微信官方色调）

| Token | 值 | 用途 |
|---|---|---|
| 品牌主色 | `#07C160` | Tab 选中、筛选选中、高亮、CTA |
| 品牌深绿 | `#06AD56` | 渐变深端、按钮填充 |
| 品牌浅绿 | `#E8F8EF` | 强调底色（词条/图标块） |
| 页面背景 | `#F7F7F7` | 全局页面灰 |
| 卡片背景 | `#FFFFFF` | 内容卡片 |
| 主文字 | `#111827` | 标题/正文 |
| 次要文字 | `#6B7280` | 副行/说明 |
| 弱文字 | `#999999` | Tab 未选中/占位 |
| 微信官方红 | `#FA5151` | 热搜榜、涨幅、警告 |
| 浅灰 | `#F5F5F5` | 图标块、标签底、分隔线 |
| 分割线 | `#E5E5E5` | Tab 顶线、描边 |

- 平台色（保留平台标识，不随品牌）：夸克 `#1A94FF` / 阿里云盘 `#FF6B38` / 百度网盘 `#2A5BF2` / 115 `#ED3D3D` / 迅雷 `#0D87E0`
